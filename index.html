ALT-03 is the one to look at. The evidence fits both a stolen password and a holiday, and nothing in the telemetry separates them — HR leave records are not wired into the security tooling. The agent does not guess. It holds, names the deciding fact, and says who can answer it. That is why the console reports 67% agreement with the human verdicts, and why that number is the right one rather than an embarrassing one.

What stops it closing a real attack

The question every manager, auditor and regulator asks first. The answer is structural, not a matter of trusting the model.

1
Pick-up & parseNo queue, no severity filter. Nothing is skipped.
2
CorrelateShared infrastructure across alerts; benign indicators excluded.
3
EnrichFive sources at once. A source that fails is a recorded data gap.
4
Hard triggersFifteen never-close rules, in code, before the model is asked anything.
5
ReasonConstrained by a strict JSON schema — a closed set of five verdicts.
6
Policy gateThe disposition is decided here. The model has no vote.

The fifteen hard triggers are evaluated against enrichment facts before the model is consulted. It can suggest one and be overruled; it cannot argue one away. A prompt injection that fully captured the model still could not auto-close an alert — and refusals, content-filter blocks and truncated answers are all treated as failures to triage, routing the alert to a human rather than being read as "nothing to see here".

Real and staged

Stated plainly, because it protects the credibility of everything else.

Real

  • The pipeline and its concurrency
  • The reasoning and the structured verdict
  • The policy gate and the hard triggers
  • Package assembly and completeness validation
  • Metrics, audit log and server-side role enforcement
  • Every latency figure on screen

Staged

  • Alerts and the five enrichment sources are fixtures, not live connectors
  • Every identity, host and domain is fictional
  • Alert pick-up is instant; in production it is bounded by SIEM surfacing
  • Model verdicts replay from cache so the demo needs no API key
